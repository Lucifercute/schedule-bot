# Schedule Bot

Telegram-бот, который читает еженедельное расписание тренировок из Google Sheets
(лист с пометкой «текущая» в названии) и по команде показывает, какие тренировки
назначены — с их статусом (проведено / отменено / назначено / назначено и подтверждено
/ перенесено на следующую неделю), определяя статус по цвету заливки ячейки.

## Как это работает

- Бот ищет в таблице лист (вкладку), в названии которого есть слово «текущая».
- Статус занятия определяется по фиксированному HEX-коду заливки ячейки (список — в
  `STATUS_COLORS` в `sheets_client.py`); коды заданы производителем таблицы и не меняются.
- Серые служебные ячейки (ФРИРАЙД, СОБРАНИЕ, ИВЕНТ и т.п.) и пустые ячейки — не совпадают
  ни с одним известным цветом и пропускаются, бот показывает только реальные клиентские тренировки.
- Отвечает только пользователю с заданным Telegram ID (см. `.env`) — расписание с именами
  клиентов и детей не должно быть доступно кому попало.

## Команды

- `/today` — тренировки на сегодня
- `/week` — тренировки на всю неделю, по дням

## Уведомления

Бот раз в 10 минут (`POLL_INTERVAL_SECONDS` в `bot.py`) сам проверяет таблицу в фоне и
присылает сообщение, если:

- появилась новая тренировка (ячейка, которой раньше не было);
- статус тренировки изменился на «Занятие назначено и подтверждено».

Снимок предыдущего состояния хранится в `state.json` (не в git). При первом запуске или
при переходе на новую неделю (новый лист «текущая») бот просто запоминает текущее
состояние без уведомлений — чтобы не присылать разом всё расписание новой недели.

## Настройка (нужно сделать один раз)

### 1. Google-сервисный аккаунт

1. Зайди в [Google Cloud Console](https://console.cloud.google.com/), создай новый проект (или используй существующий).
2. В разделе **APIs & Services → Library** включи **Google Sheets API**.
3. В разделе **IAM & Admin → Service Accounts** создай сервисный аккаунт.
4. Открой созданный аккаунт → **Keys → Add Key → Create new key → JSON** — скачается файл, переименуй его в `service-account.json` и положи в папку проекта.
5. Скопируй email сервисного аккаунта (выглядит как `имя@проект.iam.gserviceaccount.com`).
6. Открой свою Google-таблицу с расписанием → **Настройки доступа** → добавь этот email с правом **"Читатель" (Viewer)**.

### 2. Telegram-бот

1. Напиши [@BotFather](https://t.me/BotFather) в Telegram → `/newbot` → следуй инструкциям → получишь `TELEGRAM_BOT_TOKEN`.
2. Узнай свой Telegram ID — напиши [@userinfobot](https://t.me/userinfobot), он пришлёт твой `ALLOWED_TELEGRAM_USER_ID`.

### 3. ID таблицы

В URL таблицы: `https://docs.google.com/spreadsheets/d/ЭТОТ_КУСОК/edit` — это и есть `SPREADSHEET_ID`.

### 4. Конфигурация

```bash
cp .env.example .env
# впиши в .env реальные значения TELEGRAM_BOT_TOKEN, SPREADSHEET_ID, ALLOWED_TELEGRAM_USER_ID
```

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

export $(cat .env | xargs)
python bot.py
```

Напиши боту в Telegram `/today` или `/week`.

## Стек
